## 🚀 快速启动

### 环境准备
```bash
# 安装依赖
pip install -e ".[automotive]"

# 配置.env
cp .env.example .env
# 编辑 OPENAI_API_KEY=sk-xxx
```

### 启动服务
```bash
# 终端1: 启动Mock Vehicle API
python -c "from minicoder.vehicle.mock_server import main; import sys; sys.argv = ['minicoder-vehicle-api', '--host', '127.0.0.1', '--port', '8765']; main()" &

# 验证API
curl http://127.0.0.1:8765/v1/health

# 终端2: 启动REPL
python -c "from minicoder.cli import main; main()" --profile automotive
```

### 测试项目
```bash
# 运行测试
pytest

# 查看覆盖率
pytest --cov=minicoder --cov-report=term-missing

# 代码检查
ruff check .
ruff format --check .
```

## 🔍 常见问题 FAQ

### Q1: 这个项目的最大亮点是什么？
**A**: **五层架构设计 + 槽位状态机 + 安全$ref引用**。五层架构让各模块职责单一、可独立测试；槽位状态机支持3轮补全、纠错和取消；$ref机制通过PlanValidator强制前序依赖检查，拦截率100%。

### Q2: 如何体现工程能力？
**A**: 206个测试覆盖86.47%分支、GitHub Actions CI/CD矩阵、ruff代码规范、意图/知识离线评测脚本、原子会话保存与恢复、增量索引优化、重试降级策略。

### Q3: 技术难点是什么？
**A**: 
1. **槽位补全**：3轮状态机 + 纠错识别 + 取消处理
2. **安全引用**：$ref白名单 + 运行时解析 + 校验拦截
3. **分词一致性**：jieba统一配置 + 领域词典 + 后过滤
4. **增量索引**：哈希驱动 + 临时库构建 + 原子发布

### Q4: 可以扩展哪些功能？
**A**:
- 混合检索：BM25 + Embedding + RRF
- 记忆系统：短期摘要 + 长期偏好
- 多Agent复核：Planner / Executor / Reviewer
- 真实接入：OAuth + 审计日志 + 车端API

### Q5: 项目周期和代码量？
**A**: 2个月（2026.06-2026.08），7,773行核心代码，43个Python模块，206个测试用例，86.47%分支覆盖率，3次Git提交（v0.3.0）。
